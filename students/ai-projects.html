Data Dunkers Mini-Projects

Pick a project, follow the game plan, check the AI, make the call.

Read this first

Every project starts the same way

Get your data into a CSV, start a fresh chat, and tell the AI exactly what it is looking at.

Step 1: Get your dataset as a CSV file

MagicSchool can only read CSV files. Your data probably lives in Google Sheets or Excel, so download it first.

From Google Sheets: File → Download → Comma Separated Values (.csv) This downloads only the tab you have open, so click the correct tab first.
From Excel: File → Save As → CSV UTF-8 (Comma delimited) (.csv) This saves only the sheet you have open.
Check your file: Open the CSV. Row 1 should be column names. Every row below it should be one student or one player. Delete any blank rows or notes at the bottom.

Step 2: Start a fresh chat and upload

Step 3: Build your first prompt

The AI only knows what is in the file and what you tell it. Fill in the blanks, then copy your prompt.

Prompt Builder fill in, then copy
Example: basketball shooting results from our class
Example: one student, or one pro player
Copy the exact column names from row 1 of your file
I uploaded a CSV dataset about [what the data is]. Each row is one [student / player]. The important columns are: [column names]. My goal is to [what you are trying to decide]. Use only the data in the file. If something is not in the data, say so.
The Three Rules

1. Protect the data. Only upload approved files. Anonymous IDs only, never names.

2. Ask a focused question. One clear question at a time beats a vague one.

3. Check the result before using it. AI math can be wrong. Recalculate at least one number yourself and find the rows it mentions in your real file.

If the chat gets confused

Long chats drift. If answers stop making sense, start a new chat, re-upload your CSV, and re-send your first prompt with what you know so far.

Pick your project

Project 1

Build, Balance, and Predict

You are the league organizers. Build fair teams from today's class data, then predict a winner.
Dataset: Today's class data (the data you collected this morning)
0/8

Example prompts

Using the columns [your columns], split the students into [number] balanced teams. Show each team's members and each team's average for each column.
If these teams played a shooting contest, which team would win? Explain using only the data.
Stretch: Run a Tournament

Ask the AI to set up a bracket with your teams and predict each matchup winner. For every prediction, make it point to the exact numbers it used, then find those numbers in your real file.

Prepare your 2-minute share-out
  • The question you investigated.
  • The dataset you used.
  • The most important evidence.
  • Your final decision or recommendation.
  • One thing the AI said that you had to check, and what you found.

Datasets: Today's class data (Phase 1) and the NBA or WNBA player CSV (Phase 2). You will only upload the pro file.
This project has two phases

MagicSchool reads one CSV per chat. So you find the weakness with your own eyes first, then describe it to the AI in words.
